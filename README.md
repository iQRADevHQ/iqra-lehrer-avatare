# iQRA – Lehrer-Avatare

Zwölf gesichtslose Avatarentwürfe zur gestalterischen Auswahl: sechs Lehrer mit Bart und sechs Lehrerinnen mit Hijab, in drei Illustrationsstilen.

Diese eigenständige Galerie verändert die iQRA-Website nicht. Die Profilkarten verwenden deren vorhandene Beispieltexte und Kartengestaltung; sie stellen keine echten Lehrkräfte dar.

Die Avatare wurden einzeln mit dem integrierten Imagegen-Werkzeug erzeugt. PNG-Originale liegen in bilder/, kleine WebP-Ausgaben in profilgroessen/ und die vollständigen Prompts in Prompts.json.
